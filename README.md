# Janus Studio — Cinematic Hero

A single-page cinematic hero section built with React + TypeScript + Tailwind CSS + lucide-react (Vite).

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4 (via `@tailwindcss/vite`)
- lucide-react for icons

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

All markup lives in `src/App.tsx`; the liquid-glass effect and font import live in `src/index.css`. The background video is at `public/videos/janus-hero.mp4`.
